# @orchestra-mcp/ui

Orchestra MCP UI component library — desktop-first React components

Part of the [Orchestra MCP](https://orchestra-mcp.dev) ecosystem.

## Install

```bash
npm install @orchestra-mcp/ui
# or
pnpm add @orchestra-mcp/ui
```

## Usage

```tsx
import { } from '@orchestra-mcp/ui'
```

## Requirements

- React >= 18.0.0
